# DeskGPT

DeskGPT is an unofficial Linux desktop wrapper for ChatGPT.

It gives ChatGPT its own Linux desktop app window, launcher icon, tray menu, and global shortcut support without keeping it buried in browser tabs.

## Features

- Standalone desktop window
- System tray support
- Hide to tray on close
- About/version dialog
- Custom app icon
- Linux launcher integration
- AppImage packaging support

## Requirements

- Linux
- Electron
- Node.js / npm

## Run from source

```bash
npm install
npm start
